Base de datos compartida en tiempo real (Firebase)

Conecta el proyecto de Firebase de EMAT para sincronizar cotizaciones y pedidos entre todo el equipo.

¿Cómo obtener estos datos (toma 2 minutos)?

  1. Entra a console.firebase.google.com y crea un proyecto (ej. emat-comercial).
  2. En el menú izquierdo ve a Compilación → Firestore Database → Crear base de datos (modo prueba o reglas autenticadas).
  3. Ve a Configuración del proyecto (⚙️) → Tus apps → Web (</>) y copia el bloque firebaseConfig.
  4. Pégalo abajo (o pega el objeto completo) y presiona Conectar y Sincronizar.
